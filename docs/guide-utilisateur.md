# Guide de l'apprenant — PERFEKT Academy

## 1. Créer son compte
Cliquez sur **Connexion → Créer un compte**, renseignez votre nom, email et un mot de passe (8 caractères minimum).
Mot de passe oublié ? Lien **Mot de passe oublié** sur la page de connexion : vous recevez un lien valable 1 heure.

## 2. Choisir une formation
Menu **Academy** : recherchez par mot-clé, filtrez par catégorie, niveau, prix ou durée, triez les résultats.
- ♡ ajoute une formation à vos **favoris**.
- Cochez **Comparer** sur 2 ou 3 formations pour les voir côte à côte.
- La fiche détaille le programme, les prérequis, les objectifs, les compétences, les avis et la FAQ. Une vidéo d'aperçu est disponible.

## 3. Payer
Bouton **Acheter la formation** → choisissez **Flooz**, **Mixx by Yas**, **carte bancaire** ou **paiement international**.
Saisissez un code promo si vous en avez un. Après validation, l'accès est immédiat et la **facture / reçu** est téléchargeable.

## 4. Suivre les cours
**Mon espace → Mes formations → Commencer / Reprendre**.
- Les vidéos reprennent automatiquement là où vous vous êtes arrêté ; la vitesse (0,75× à 2×) se règle en haut à droite.
- Une vidéo vue à 90 % est marquée comme terminée ; les autres leçons se valident avec **Marquer comme terminé**.
- **Mes notes** : prise de notes sous chaque leçon, enregistrées automatiquement (retrouvez-les dans *Mon espace → Mes notes*).
- **Discussion** : échangez avec les autres apprenants ; cochez *Question au formateur* pour une question directe.
- Les supports PDF se téléchargent si l'administrateur l'autorise.
- Exercices / projet final : déposez votre travail (lien + description) ; la note du formateur apparaît dans la leçon.

## 5. Obtenir l'attestation
Quand toutes les leçons sont terminées, l'**examen final** se débloque. Avec le score minimum (70 % par défaut),
l'attestation est générée automatiquement : *Mon espace → Attestations → PDF*.
Chaque attestation possède un numéro unique et un QR code ; toute personne peut vérifier son authenticité sur **/verifier**.

## 6. Sécurité du compte
*Mon espace → Profil & sécurité* : photo, informations, mot de passe et **appareils connectés**.
Le nombre d'appareils connectés en même temps est limité : une nouvelle connexion déconnecte l'appareil le plus ancien.
